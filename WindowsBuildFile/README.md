# Negative Space

A 2D game made in Unity for GameJam,





This is a Windows 10/11 version just run the Negative Space.exe to play.



Player Controls: A/D key or arrow key to move sideways and Space to Jump.



Asset Description: All assets other than 3 were made in Canva,
